# DanielOu1208 Agentslate

## How do I install these formulae?

`brew install danielou1208/agentslate/<formula>`

Or `brew tap danielou1208/agentslate` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "danielou1208/agentslate"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
